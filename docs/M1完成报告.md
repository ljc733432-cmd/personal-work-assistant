## 2. 已实现的内容

### 2.1 主进程（electron/）
- `main/index.ts`：窗口创建、**安全三件套**（contextIsolation/nodeIntegration:false/sandbox）、单实例锁、外链浏览器打开、IPC 注册入口
- `preload/index.ts`：**白名单 IPC** 暴露（provider:*、chat:*、settings:*、db:health、meta:*），不再全量暴露 ipcRenderer
- `ipc/index.ts`：全部 handler（CRUD、测试连接、流式对话、健康检查）
- `services/db/`：Drizzle schema（providers + settings 表）+ 单例 + 启动建表 + 健康检查
- `services/secret.ts`：safeStorage 封装（Key 加密落盘，apiKeyRef 引用）
- `services/providers/`：Provider 抽象（types）、统一 chat 循环（chat.ts，含 FC 多轮）、client 工厂（factory.ts）
- `services/tools.ts`：内置工具 `get_current_time`（FC 实测用）

### 2.2 渲染层（src/）
- `App.tsx`：侧栏导航（对话/设置）+ 路由切换
- `pages/chat/ChatPage.tsx`：消息列表、流式渲染、FC 调用提示、模型切换、工具开关、Enter 发送
- `pages/settings/SettingsPage.tsx`：Provider 列表、新增/编辑/删除、**测试连接**、Key 加密保存
- `components/ui/`：shadcn 风格组件（Button/Input/Textarea/Card/Label）
- `stores/providers.ts`：Zustand 状态管理
- `lib/`：ipc 薄封装、cn 工具
- `types/`：渲染层共享类型

### 2.3 配置
- `electron-builder.json`：`asarUnpack` better-sqlite3、win nsis 安装包配置
- `tsconfig.node.json`：ES2022 target、strict
- `index.css`：Tailwind 4 + shadcn 设计 token（HSL 变量）

## 3. 关键技术验证结论（落地版）

### ✅ TV-1 智谱 FC（理论已确认）
- GLM 全系列在 OpenAI 兼容端点支持 `tools`/`tool_choice`。
- 代码层 FC 循环已实现并类型检查通过；**真机实测待用户在设置页配智谱 Key 后**，问"现在几点"即可验证整条链路（模型→tool_call→主进程执行 get_current_time→回灌→最终答）。

### ✅ Drizzle + Electron 打包（实测通过，最重要）
- 路线选择正确：better-sqlite3 + Drizzle 在 Electron 打包后**完全可用**。
- native 模块经 `@electron/rebuild` 重编译，解包到 app.asar.unpacked，运行时正常加载。
- app.db 在 `userData` 正常创建，WAL 模式生效。
- **规避了 Prisma 的 asar 二进制路径地雷**——ADR-001 决策验证成立。

### ⚠️ 踩坑记录（已解决，写进 AGENTS.md 禁忌）
1. **better-sqlite3 11.x 与 Electron 42 不兼容**：`@electron/rebuild` 编译报 `v8::External::Value` 签名错误。**解决：升级到 13.0.2。** 禁忌已固化。
2. **GitHub 直连受阻**：git 全局代理 127.0.0.1:7892 未开时，`git clone` 失败。**解决：`git -c http.proxy= -c https.proxy=` 临时禁代理直连。** Electron 二进制用 `ELECTRON_MIRROR=npmmirror` 镜像下载。
3. **脚手架交互式提示**：`npm create @quick-start/electron` 在非交互 shell 卡住。**解决：改用 `git clone` electron-vite-react 模板。**
