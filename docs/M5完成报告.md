## 1. 目标场景

> 用户说"总结我 8 月 3 日的报告"，AI 自己 `find_files(dateTo=2026-08-03, ext=md)` → 命中 → `read_file` → 总结。

不用手动拖文件，AI 在白名单里自己找、自己读。

## 2. 已实现内容

### 2.1 数据层
- 新表 `work_dirs`：`{id, label, path, mode(read|readwrite), enabled}`
- 启动自动建表（沿用 M1 的 BOOTSTRAP_SQL 机制）
- factory 加 `listEnabledWorkDirs()` / `listAllWorkDirs()`

### 2.2 文件工具核心（`services/fileTools.ts`）
- **`resolveSafePath()`** — 安全心脏：解析路径防 `../` 逃逸，校验必须落在白名单内，forWrite 时校验必须是 readwrite 目录
- `listFiles()` — 列目录（名/大小/修改时间，上限 200 条）
- `readFileContent()` — 读文件，支持 txt/md/json/csv/代码 + **pdf（pdf-parse）+ docx（mammoth）**，大文件截断（2 万字符）
- `findFiles()` — 递归扫描，按**文件名关键词 + 修改日期范围 + 扩展名**过滤，上限 50 条
- `moveToTrash()` — 覆盖前移到 `userData/fileTrash/{timestamp}/`

### 2.3 可挂起 FC 循环（`services/providers/chat.ts` 改造）
- tool handler 返回值从 `string` 扩展为 `ToolHandlerResult` 联合类型：
  - `{kind:'result', value}` — 直接回灌（兼容旧 string 返回）
  - `{kind:'confirm', prompt, action}` — 挂起等用户确认
- FC 循环遇 confirm → `await onConfirm(prompt)` → 主进程推 `chat:confirm_request` → 前端弹窗 → 用户选 → resolve → 执行 action
- **这是 M5 技术核心**：让"覆盖确认"成为 FC 流程的一等公民

### 2.4 动态工具组装（`services/tools.ts` 重写）
`assembleTools(workDirs)` 按白名单动态注册：
- 始终：`get_current_time`
- 有任意 WorkDir：`list_files` + `read_file` + `find_files`
- 有 readwrite WorkDir：额外 `write_file`
- **无 WorkDir：不注册任何文件工具**（模型不知道有这能力，双保险）

### 2.5 IPC（`electron/ipc/index.ts`）
- 新增：`workdir:list/upsert/delete/pick`（pick 调系统目录选择对话框）
- `chat:send` 改为按 workDirs 动态组装工具
- 新增 `chat:confirm_request`（主→渲染）+ `chat:confirm_response`（渲染→主），配合 reqId→resolver 映射实现挂起

### 2.6 UI
- 设置页：**「工作目录」管理区**（增删改、浏览选目录、只读/读写单选、启用开关）
- 聊天页：**确认弹窗**（write_file 覆盖时弹出，用户选允许/拒绝）

## 3. 安全约束（强制，已实现）

| 防护 | 实现 |
|---|---|
| 路径校验 | `resolveSafePath` 防 `../` 逃逸 + 白名单内校验 |
| 只读目录禁写 | forWrite 时校验 mode，且 write_file 工具根本不注册给只读场景 |
| 写入三重防护 | ①路径校验 ②覆盖确认弹窗 ③原文件进回收站 |
| 大小限制 | 读 10MB / 写 5MB |
| 越界拒绝+日志 | resolveSafePath 失败走 logError |

## 6. 关于"联网搜索"（PRD M5 另一半）

## 7. 踩坑记录
- **pdf-parse ESM 导入报错**：`import('pdf-parse').default` 在新版本类型不对。改用 `createRequire` + `require('pdf-parse')` 绕开 ESM/CJS 导出差异。mammoth 同理。
- **IpcResult 泛型里写 ReturnType**：`IpcResult<ReturnType<typeof fn>>` 在运行时位置非法（TS1005）。改成显式 `IpcResult<WorkDir[]>`。
